# 🎸 Guitar HQ

## Vision du projet

Guitar HQ est une application personnelle de pratique conçue pour redevenir un guitariste actif après une pause d'environ 2 ans.

L'objectif principal n'est pas la vitesse ou la virtuosité, mais :

- Retrouver une pratique régulière
- Développer une connaissance solide du manche
- Jouer davantage de musique
- Improviser plus librement
- Composer des riffs personnels
- Exploiter pleinement le matériel existant

---

# Priorité absolue

## 🧠 Fretboard Mastery

Plus grande faiblesse identifiée :

- Connaissance du manche

Objectif 12 semaines :

- Reconnaître instantanément les notes naturelles
- Maîtriser les cordes E et A
- Comprendre les octaves
- Comprendre les quintes
- Comprendre les tierces
- Visualiser les fondamentales dans les pentatoniques
